# ReSmartBox landing page

Static Vietnamese landing page for the ReSmartBox project.

## Publish with GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site whenever code is pushed to `main`.

1. Push the website files and folders to the `main` branch of the GitHub repository.
2. In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.
3. Open **Actions** and wait for **Publish ReSmartBox landing page** to complete.
4. The deployed URL will appear in the workflow run and in **Settings → Pages**.

Keep the `Anh_lap_dat`, `Anh_minh_chung_giayto`, `Anh_thanhvien_va_chuyengia`, and `video_demo` folders in the repository so the page can load its images and videos. The two demo videos larger than 25 MB need to be pushed with Git (or GitHub Desktop); GitHub's browser file uploader does not accept files that large.
